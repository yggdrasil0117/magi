# MAGI UI-D4b-2b PostgreSQL 操作存储

状态：已实现并通过本地验证。

## 成果

- 新增 PostgreSQL 异步操作表和只追加公开事件表。
- 接受操作与第一条 `accepted` 事件在同一事务写入。
- 同一主体和幂等键重复请求会返回同一回执。
- 同一幂等键不能同时用于同步命令和异步操作。
- 原始主体和原始幂等键不入库；请求 JSON 按决策数据等级受控保存。
- 回执查询使用主体摘要隔离，其他用户得不到操作是否存在的信息。
- 事件查询支持严格递增游标、100 条上限和 `has_more`。
- 已成功操作中的结果必须通过 `DecisionView` 校验，损坏记录关闭失败。

## 尚未激活

本增量没有启动后台工作器，也没有开放新 HTTP 路由。下一增量 UI-D4b-2c 将实现任务领取、
租约、fencing、advisory lock、状态/事件原子迁移与崩溃恢复。
