# MAGI UI-D4a 生产基础层

状态：已采用；UI-D4b-1 确认与取消已单独实现。

## 本轮成果

- 生产 Web 首页从“只读最终报告”升级为完整的只读 `DecisionView` 工作区。
- 用户可使用已知决策 ID、版本和内存令牌读取真实 API 状态。
- 页面展示规范化问题、候选项、约束、未知项、公开证据、可披露三方意见、
  服务端声明的可用操作和最终报告。
- 第一轮评估时强制隐藏 ballot；即使上游错误携带字段，展示层也不披露。
- 交叉复核时已释放的第一轮意见会被明确标为临时意见。
- 继续复用 M3 权威报告渲染器，不重新计算投票或结果。

## 安全边界

- Web 服务只绑定本机回环地址。
- 代理只允许合法 UUID 的决策 GET 和 JSON 报告 GET。
- 令牌不进入 URL、Cookie、localStorage 或 sessionStorage。
- 响应最大 1 MB，设置 `no-store`、CSP、`nosniff` 和拒绝嵌入。
- 外部内容使用 `textContent` 写入 DOM。
- 未知 schema 和未知状态会关闭失败，不猜测展示。

## 暂不伪造的能力

当前 API 仍没有授权决策列表、全局权限投影、新版本命令、公开事件回放和完整审计接口。
因此生产页面诚实显示“已知 ID 访问”，不用测试数据假装收件箱。

## UI-D4b 建议分层

1. D4b-1：先接入确认和取消，包含后果说明、二次确认和内存幂等键。
2. D4b-2：确定长时间命令模型后再接入创建和运行。
3. 优先建议后端返回命令回执并提供事件重放，避免浏览器超时被误判为运行失败。

回复“UI-D4a 采用”后，可进入 UI-D4b-1。
