# MAGI M5c 验收摘要

版本：`0.5.0a3`

M5c 已完成 Web/TUI 评估展示同构：两端均从 M5b 权威 API 读取五项指标、
最近状态、窗口趋势与追加历史，不在客户端重新计算评分。

## 已交付

- EVA 风格 Web 五指标卡、趋势窗、历史序列与终态运行入口。
- `evaluation:read` 拒绝时局部降级，不影响决策工作区。
- TUI `evaluations` 与 `evaluate` 命令及控制字符安全展示。
- 延迟或价格样本缺失时明确显示“未测量 / NOT MEASURED”。
- Web 身份、摘要、顺序和趋势一致性校验，以及跨客户端契约测试。

## 安全边界

Web 运行请求只发送当前决策版本。投票、阈值、价格和指标值均不能由
客户端提交；展示结果来自追加式服务端记录。令牌仍仅保留在页面内存。

M5 尚未关闭；下一增量处理代表性真实运行套件与最终验收。
