# MAGI M5 验收摘要

版本：`0.5.0`

M5 已完成本地实现验收。Web、终端 TUI 与自动化 CLI 共享公开 API 和
DecisionView；评估展示统一读取服务端追加式历史，不在客户端计算投票、
评分、成本或趋势。

## 关闭项

- 五项确定性指标：引用、人格差异、裁决一致性、P95 延迟与模型成本。
- PostgreSQL 追加式历史、精确结果去重、权限分离与趋势窗口。
- EVA 风格 Web 指标面板和键盘优先 TUI 评估面板。
- 共识、复核改票、信息不足、人格缺失、性能失败和非法引用校准矩阵。
- Web/TUI 共用同一份版本化评估历史夹具，防止跨客户端语义漂移。
- 可选真实 PostgreSQL/OpenAI 全链路评估与重启恢复门控。

真实服务测试默认关闭，未配置凭据时记为环境门控跳过，不记为通过。
这不影响 M5 本地实现退出标准；部署前应在隔离测试数据库上显式运行。
当前校准矩阵是合成工程夹具，不等同于真实用户偏好研究或人工决策质量背书。

本地回归结果：Python `210` 项通过、`4` 项环境门控跳过；Web `26` 项通过。
