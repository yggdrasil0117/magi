# MAGI M2b-2b 实现摘要

版本：0.2.0b3  
状态：代码和本地协议测试完成；真实 PostgreSQL 重启测试待数据库环境验证

## 本轮完成

- 增加 PostgreSQL 持久化运行时，共享一个异步连接池。
- 增加模型调用流水表和规范投票表。
- 使用 PostgreSQL advisory lock 防止多进程重复调用同一模型请求。
- 将成功调用记录与规范投票放入同一事务。
- 接入 LangGraph `AsyncPostgresSaver`，支持中断状态跨应用重启恢复。
- 限制检查点反序列化模块范围，降低不安全对象反序列化风险。
- 增加无数据库协议测试和可选真实 PostgreSQL 重启集成测试。

## 验证结果

- 全套测试：61 项。
- 通过：59 项。
- 跳过：2 项。
- 跳过原因：LangGraph 已安装时不适用的缺依赖测试，以及当前机器没有
  Docker/PostgreSQL 连接而未运行的真实重启测试。
- 源码编译、100 字符行宽与安全序列化往返检查均通过。
