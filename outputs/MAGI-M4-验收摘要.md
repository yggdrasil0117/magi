# MAGI M4 验收摘要

版本：0.4.0

M4 已完成受控 HTTPS 证据检索、证据冻结与哈希、引用边界校验、追加式审计、
脱敏覆盖、报告重建，以及受权 Web/TUI/CLI 审计界面。

审计权限与普通决策读取权限分离。读取需要 `audit:read`，脱敏需要
`audit:redact` 与幂等键。脱敏不会更新或删除规范记录；Web 会明确显示完整性、
哈希、脱敏字段和权限不足状态。

本地自动化验收覆盖 API 权限、幂等冲突、哈希链篡改、PostgreSQL 追加保护、
报告重建、代理路径白名单、键盘访问和跨客户端命令。真实 PostgreSQL/OpenAI
部署验证继续由环境变量显式启用。
