# MAGI M3 验收摘要

版本：0.3.0

M3 交叉评审与报告里程碑已完成本地验收：

- 三人格首轮隔离，并且只接收另外两方的脱敏摘要；
- 高风险决策强制进入一次交叉评审，不允许递归讨论；
- 每张第二轮选票必须说明保留或改票的原因；
- 最终报告由密封记录确定性生成，多数结论必须保留少数意见；
- JSON、Markdown、终端和 Web 均消费同一份权威报告；
- 终端清除外部控制字符，Web 使用纯文本 DOM 和同源代理；
- 共享多数报告夹具验证两种界面保留相同的结论、票数、异议和审计链。

真实 PostgreSQL/OpenAI 冒烟测试仍按显式环境开关执行，不会被本地测试误触发。
