# MAGI M3b 实现摘要

版本：0.3.0a2

本次增量完成最终报告的独立读取与安全导出：

- 新增经过身份认证和逐决策授权的 JSON 报告接口；
- 新增内容一致的 Markdown 附件下载接口；
- 未完成仲裁的决策返回稳定的 `report_not_ready`，不生成半成品；
- Markdown 由确定性代码渲染，不调用模型，也不改变投票和仲裁字段；
- 对外部文本折叠换行并转义 Markdown 控制符；
- JSON 和 Markdown 均禁止共享缓存，并启用 `nosniff`；
- 导出复用 `decision:read` 权限，不扩大数据访问范围。

下一增量将实现终端与 Web 的并行报告展示，并完成 M3 验收收口。
