# MAGI M2c-5 实现摘要

版本：0.2.0b9

本阶段完成了经过认证的决策创建与准备链路：

- 新增 `POST /v1/decisions` 原子创建/准备命令；
- 生产组合入口正式构建并注入不参与投票的 Coordinator；
- 决策 ID 由认证主体和幂等键确定性生成，跨进程重试不会创建第二条线程；
- 准备请求指纹写入检查点，恢复时不会再次调用 Coordinator 或接受变化输入；
- 证据 ID、内容哈希和 `user_asserted` 状态由应用层封装；
- 创建成功后停在用户确认门，不提前运行三人格；
- 创建失败使用稳定错误响应且不泄露问题正文或模型提供方详情；
- 静态认证策略必须显式授予 `decision:create`，并要求创建者采用
  `allow_all_decisions: true`。

验证结果：117 项测试中 115 项通过，2 项真实 PostgreSQL 测试因环境未配置
而按预期跳过；自动测试没有发起真实 OpenAI 请求。

M2 还剩 1 次修改：M2c-6 验收收口，包括真实 PostgreSQL/OpenAI 受控冒烟、
数据库就绪检查和最终 M2 验收记录。
