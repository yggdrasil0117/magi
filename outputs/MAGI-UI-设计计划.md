# MAGI UI 设计计划摘要

UI 不再作为 M5 末尾的“美化工作”，而是贯穿 M4 和 M5 的独立交付轨道。

计划分为五个确认阶段：

1. UI-D1：用户流程、信息架构、页面清单和状态矩阵；
2. UI-D2：Web 与终端低保真线框，确认信息优先级与操作；
3. UI-D3：视觉基线、设计变量、组件契约、响应式与无障碍规则；
4. UI-D4：先实现 TUI 工作流，再实现 Web 与 CLI；
5. UI-D5：可用性、键盘、无障碍、多尺寸和跨客户端一致性验收。

Web 与终端共享状态含义、信息层级和 API 契约，但不要求像素级相同。
最终报告必须显式保留少数意见、证据、风险、未知项和审计链；颜色不能
成为唯一状态提示。

下一步是在 M4 功能界面开发前完成 UI-D1，并逐层确认后再进入视觉设计。
