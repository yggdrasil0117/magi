# MAGI UI-D3 视觉基础提案

状态：待确认。确认后进入 UI-D4 生产组件与完整工作流实现。

## 已确定的方向

- 黑色和暖炭灰构成默认背景，琴珀色负责日常信息和结构线。
- 红色仅用于失败、拒绝、不安全或视角不可用，不让产品永远处于警报状态。
- MELCHIOR、BALTHASAR、CASPER 采用等尺寸模块、编号和不同线型区分，颜色不表示权重。
- 中文推理使用可读无衬线字体；状态大字使用系统窄体；ID、时间和协议字段使用等宽字体。
- 控件最小高度 44 px，键盘焦点使用 3 px 明亮轮廓，状态不依赖颜色独立表达。
- 提供“指挥模式”和“阅读模式”，后者隐藏可选素材并降低装饰密度。

## 可视化成果

使用浏览器直接打开 `apps/web/prototypes/ui-d3.html`。页面可切换：

1. 确认与冻结；
2. 已完成的多数报告；
3. 三视角不完整的降级恢复。

页面中的标志是本仓库原创的“三单元＋中央决策点”回退标志。取得授权后，
可在不改变布局的前提下替换为 NERV 或其他官方素材。

## 终端映射

- 256 色终端使用琴珀、红、绿、暖白和灰色的近似色。
- 无色模式保留 `[WAIT]`、`[READY]`、`[ALERT]`、`[DONE]` 以及 M-01/B-02/C-03。
- 终端不显示官方位图，字符画也需在授权范围内才能表达官方标识。
- 低于 80 列时改为纵向内容，不删除异议、后果说明和恢复操作。

## 请确认的 6 项

1. 采用琴珀/暖黑作为常态，红色仅用于真正警报。
2. 采用系统窄体与等宽字体，不复制影视作品字体。
3. 采用状态横幅、切角面板、三视角单元、操作门、异议面板和素材位契约。
4. 采用“指挥模式＋阅读模式”两种密度。
5. 采用原创三单元标志作为未授权构建的默认标志。
6. 采用当前响应式、动效、终端、焦点和无障碍规则。

回复“UI-D3 采用”即可冻结这六项，然后进入 UI-D4。
