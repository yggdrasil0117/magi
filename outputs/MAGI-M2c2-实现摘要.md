# MAGI M2c-2 实现摘要

版本：0.2.0b5  
状态：共享应用服务与 DecisionView 完成，本地验证通过

## 本轮完成

- 增加 Web、终端 TUI 和 CLI 将共同使用的应用服务。
- 将“用户确认”和“开始三人格投票”拆成两个状态机命令。
- 确认后停在 `EVIDENCE_READY`，显式执行 `run` 才启动投票。
- 支持从另一个应用服务实例读取并恢复同一检查点。
- 增加统一 `DecisionView`，不向客户端暴露 LangGraph 内部状态。
- 首轮汇总前隐藏所有选票；最终裁决前隐藏复审票。
- 同时从客户端视图和模型提示中排除 restricted 证据。
- 相同准备请求可安全重放，不同案例或证据会返回冲突。

## 验证结果

- 全套测试：83 项。
- 通过：81 项。
- 跳过：2 项，分别为已安装 LangGraph 时不适用的缺依赖测试和未配置
  PostgreSQL 测试数据库的真实重启测试。
- 源码编译、行宽、差异和敏感信息检查通过。
