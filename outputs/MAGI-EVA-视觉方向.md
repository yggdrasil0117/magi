# MAGI EVA 风格视觉方向摘要

UI 视觉方向确定为原创的 EVA/MAGI 控制终端风格，而不是普通深色或泛赛博朋克。

核心规则：

- 黑色和暖深灰作为基础，琥珀橙作为日常信息色；
- 红色只用于失败、拒绝、破坏性操作和真正警报；
- 使用非对称网格、切角、粗线框、编号、坐标标记和有限警戒条纹；
- 标题采用紧凑工业感，ID、时间、哈希和状态采用等宽字体；
- MELCHIOR、BALTHASAR、CASPER 使用平等的三模块结构和独立标记；
- 不添加虚假百分比、无意义遥测或伪系统数据来制造“科技感”；
- Web 保持响应式和文字可读性，终端使用自身的框线与键盘交互语言；
- 减少持续闪烁和常驻红色警报，并支持低动态、无声音和无颜色模式。

项目不会直接复制 NERV 标志、原作截图、角色图、现成界面、口号或受版权保护
字体。相似性来自信息密度、警报层级、几何结构和三系统构图，所有项目素材保持
原创。

UI-D1 的视觉方向已经确认；仍需确认信息架构提案中的第 1–4 项，之后进入 UI-D2
Web 与终端线框设计。
