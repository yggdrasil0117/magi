# MAGI UI-D4b-1 确认与取消

状态：已采用；确认与取消契约已冻结。

## 已实现

- 只有 `DecisionView.available_actions` 中存在 `confirm` 或 `cancel` 时，页面才显示对应按钮。
- 确认命令会冻结当前版本，对话框明确说明“不会启动模型”。
- 取消命令会停止未完成工作流，但不删除案例、证据和审计记录。
- 取消原因可选，最长 2000 字符，外部控制字符会被清理。
- 命令仅在用户第二次确认时创建，并冻结请求体、时间戳和内存幂等键。
- 请求超时时不宣称命令失败，而是显示“结果未知”。
- 重试使用完全相同的请求体和幂等键，避免生成第二条命令。
- 待重试命令存在时，不允许创建另一种写操作。
- 成功后立即渲染 API 返回的新 `DecisionView`。

## 代理安全

- GET 仍只允许决策视图和 JSON 报告。
- POST 只允许合法 UUID 下的 `/confirm` 和 `/cancel`。
- `/run`、全局 `/decisions` 创建、未知路径和其他 HTTP 方法仍被拒绝。
- 命令请求体限制为 10 KB，响应限制为 1 MB。
