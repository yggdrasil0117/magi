# MAGI M4a 受控证据检索网关

版本：0.4.0a1

M4a 已实现从显式 HTTPS 来源读取文本证据，并在三人格投票前完成规范化、
SHA-256 哈希、时间戳、证据编号和快照冻结。

安全边界采用默认关闭：只有生产配置中列出的精确域名可访问；禁止 HTTP、
账号密码 URL、自定义端口、IP 地址、重定向、环境代理、私网 DNS 结果和连接
地址漂移。响应仅接受有大小上限的 UTF-8/ASCII 文本、HTML 或 JSON。

`verified` 表示检索来源与内容指纹经过网关确认，并不表示网页陈述必然真实。
网页内容始终以不可信证据进入模型上下文，不能成为系统指令。

本增量尚未宣告整个 M4 完成。下一阶段需要实现独立于 LangGraph checkpoint
的追加式审计记录、脱敏事件，以及从规范记录重建最终报告。
