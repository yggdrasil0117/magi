# MAGI M4b 追加式审计与重建

版本：0.4.0a2

M4b 已将规范审计记录从 LangGraph checkpoint 中分离。每个决策版本形成独立
的 SHA-256 哈希链，记录顺序、前序哈希、负载哈希与封装哈希均会在读取时验证。

PostgreSQL 使用事务级 advisory lock 串行化追加，并通过触发器拒绝对审计表的
UPDATE 和 DELETE。重复命令使用稳定记录身份复用原记录，可在 checkpoint 已写入、
审计暂时失败后通过读取或重试完成修复。

脱敏采用追加式覆盖事件，不修改原始规范记录。可见审计导出显示 `[REDACTED]`，
但最终报告仍能从完整原始链重新计算，从而同时保留隐私操作历史与可复现性。

下一增量 M4c 将补充受权审计/脱敏 API，以及 EVA 风格 Web/TUI 的证据来源、
审计历史、完整性失败和脱敏状态界面。
